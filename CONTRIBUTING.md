# CONTRIBUTING

This repository is a derivative project. It begins from the starter files in `starter/`, which are copies of the originals on AETHER-ENGINEERS/AETHER-ENGINEERS.

## Preservation of script

Clause 7 of LICENSE: the entire license script remains at the top of future builds. Do not alter LICENSE. Do not ship a build whose first document is a rewritten license.

New documents may follow LICENSE. They may not replace it.

## How work enters this repo

1. Copy or leave `starter/` untouched. That directory is the transparent origin, not a scratch pad.
2. Create a branch from `main`.
3. Put new work on the branch.
4. Open a pull request.
5. Human and AI review the PR.
6. Nothing lands on `main` until that review says it is ready.

Automated agents (including Grok) do not push finished doctrine to `main` of this repo or to AETHER-ENGINEERS/AETHER-ENGINEERS. Automated pushes belong on a new branch or in a new project that still starts from the original files in their original state.

The profile repository AETHER-ENGINEERS/AETHER-ENGINEERS is a starter and a record. It is not the living workbench.

PROCESS.md records what happened, including mistakes. Do not delete process notes to make the tree look clean.
